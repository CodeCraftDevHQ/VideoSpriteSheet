# VideoSpriteSheet

[English](README.md)

برنامه‌ای دسکتاپ برای ویندوز که ویدیو را به فریم‌های جدا تبدیل می‌کند، در صورت نیاز با یک مدل هوش مصنوعی آفلاین بکگراند هر فریم را حذف می‌کند و نتیجه را به صورت اسپرایت‌شیت (یا تک‌تک عکس‌های PNG) ذخیره می‌کند.

## امکانات

- درگ‌ودراپ ویدیو روی پنجره یا انتخاب با دکمه
- پخش‌کننده داخلی با نوار زمان: دسته‌های آبی را بکشید تا بازه تبدیل مشخص شود (یا ثانیه شروع و پایان را تایپ کنید)
- گرفتن یک عکس در هر N فریم
- حذف بکگراند قابل خاموش/روشن شدن، کاملاً آفلاین (ONNX Runtime؛ کارت گرافیک با DirectML و بازگشت خودکار به CPU)
- ذخیره تک‌تک عکس‌ها، اسپرایت‌شیت یا هر دو؛ تعداد ستون، فاصله و اندازه عکس قابل تنظیم
- خروجی به‌طور پیش‌فرض کنار ویدیو ذخیره می‌شود؛ هر پوشه‌ای را می‌توانید انتخاب کنید
- تعیین پوشه ذخیره مدل‌های دانلود شده (در تنظیمات)
- رابط فارسی و انگلیسی، تم روشن / تاریک / مطابق سیستم

## پیش‌نیازها

- ویندوز ۱۰ یا ۱۱ (۶۴ بیتی)
- .NET 10 SDK برای ساخت، یا .NET 10 Desktop Runtime برای اجرا
- کارت گرافیک سازگار با DirectX 12 برای شتاب‌دهی (اختیاری؛ روی CPU هم کار می‌کند)

## ساخت و اجرا

فایل `VideoSpriteSheet.csproj` را در ویژوال استودیو باز کنید و F5 بزنید، یا:

```
dotnet run -c Release
```

## روش استفاده

1. ویدیو را روی پنجره رها کنید.
2. در صورت نیاز بازه را روی نوار زمان و مقدار «هر چند فریم یک عکس» را تنظیم کنید.
3. «تنظیمات پیشرفته حذف بکگراند» را باز کنید، یک مدل انتخاب و دانلود کنید (فقط بار اول).
4. تعیین کنید تک‌تک عکس‌ها، اسپرایت‌شیت یا هر دو ذخیره شوند و «شروع» را بزنید.

## مدل‌های حذف بکگراند

مدل‌ها داخل این مخزن نیستند؛ در صورت نیاز از Hugging Face دانلود و در پوشه مدل‌ها (تنظیمات) ذخیره می‌شوند.

| مدل | مجوز | توضیح |
|---|---|---|
| [RMBG-1.4](https://huggingface.co/briaai/RMBG-1.4) | bria-rmbg-1.4 (غیرتجاری) | کوچک و سریع؛ برای استفاده تجاری مجاز نیست |
| [BiRefNet Lite](https://huggingface.co/onnx-community/BiRefNet_lite-ONNX) | MIT | لبه‌های بهتر، سبک‌تر از نسخه کامل |
| [BiRefNet](https://huggingface.co/onnx-community/BiRefNet-ONNX) | MIT | بهترین کیفیت، حدود ۹۷۳ مگابایت و حافظه گرافیکی بیشتر |

برای مدل‌های BiRefNet پیش‌تنظیم «ImageNet» را انتخاب کنید. هر مدل ONNX دیگری که ماسک تک‌کاناله بدهد را هم می‌توان دستی انتخاب کرد. پیش از استفاده تجاری از خروجی، مجوز مدل را بررسی کنید.
